# 세계적 상품 교역 - 인도양 무역 시뮬레이션 🌊

고등학교 세계사 수업에서 활용할 수 있는 웹 기반 역사 시뮬레이션 게임입니다.
학생들은 인도양 무역망의 상인이 되어 지역별 특산물을 교역하고, **직접 이동(육상·해상)**과 **중계무역**의 차이를 시간과 비용을 통해 직관적으로 체험할 수 있습니다.

---

## 🎯 수업 및 학습 목표
1. **지역별 특산물 이해**: 중국(비단·도자기), 동남아시아(향신료), 인도(면직물), 아라비아(향료·직물), 동아프리카(금·상아) 등 지역마다 생산 및 교역되는 상품의 차이를 파악합니다.
2. **다양한 교역로 경험**: 바닷길(⛵ 계절풍을 활용한 인도양 해상 항로)과 육로(🐪 중앙아시아를 경유하는 비단길 실크로드)의 이동 시간과 운송 비용을 비교합니다.
3. **직접 이동 vs 중계무역 체감**:
   - **직접 이동**: 현지 원가로 구매할 수 있으나 왕복 이동 일수, 운송비, 체류 중 일일 생활비(고정 운영비)가 크게 발생.
   - **중계무역**: 이동하지 않고 1일 만에 먼 지역의 물품을 확보할 수 있으나 높은 중계 수수료(35%) 발생.
4. **역사적 탐구 연결**: 게임 종료 후 제공되는 결과 분석표와 핵심 질문을 바탕으로 역사 학습지 작성 및 토론에 연계합니다.

---

## 🕹️ 게임 진행 방식 (총 3라운드, 20일간의 여정)

| 라운드 | 학습 주제 | 활동 기간 | 주요 기능 |
| :--- | :--- | :---: | :--- |
| **1라운드** | **지역 내 교역** | 4일 (1~4일차) | 현재 위치(인도) 내에서 상품 구매 및 판매 |
| **2라운드** | **직접 이동 교역** | 8일 (5~12일차) | ⛵ 해상 항로 및 🐪 중앙아시아 육상 비단길 이동 해금 |
| **3라운드** | **중계무역** | 8일 (13~20일차) | 🤝 중계무역상 원격 발주 및 직교역 vs 중계무역 비교 분석기 해금 |

* 새로운 라운드가 시작되어도 이전 라운드에서 배운 기능(구매, 판매, 이동 등)과 자금, 상품, 위치는 그대로 유지됩니다.

## ⏱️ 시간 및 경제 시스템 규칙
- **날짜 시스템**: 단순 횟수 제한이 아닌 게임 속 날짜(Day)가 흐릅니다.
  - 상품 구매: 1일 소요
  - 상품 판매: 1일 소요
  - 중계무역: 1일 소요
  - 인접 해상 이동: 2일 소요
  - 중앙아시아 경유 육상 이동: 4일 소요
- **일일 고정 운영비**: 매일 **5 냥**(식비, 숙박비, 인건비)이 자동으로 차감됩니다. (이동 중에도 동일하게 발생)
- **중계 수수료**: 중계무역 이용 시 상품 원가의 **35%**가 수수료로 부과됩니다.
- **수량 일괄 거래**: 수량 조절 버튼(+/- 및 1개, 3개, 5개, 최대)을 통해 한 번의 거래 행동으로 대량 거래가 가능합니다.
- *경제 수치는 역사 학습을 위한 교육용 가상 수치입니다.*

## 🚀 실행 및 배포 방법

### 1. 로컬 환경에서 바로 실행하기 (별도 설치 불필요)
- 프로그래밍 초보자도 손쉽게 사용할 수 있습니다.
- `indian_ocean_trade` 폴더 안의 `index.html` 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge), 사파리(Safari) 등의 웹 브라우저에서 바로 실행할 수 있습니다.

### 2. GitHub Pages 무료 배포하기
1. GitHub 저장소에 본 폴더의 파일들을 업로드합니다.
2. 저장소의 `Settings` → `Pages` 메뉴로 이동합니다.
3. Branch를 `main` 또는 `master`로 설정하고 저장하면 무료 웹 링크가 생성되어 학생들에게 즉시 배포할 수 있습니다.

## ⚙️ 교사용 맞춤 설정 안내 (`script.js`)
`script.js` 파일 최상단의 `GAME_CONFIG` 객체에서 수업 상황에 맞게 수치를 쉽게 수정할 수 있습니다:
```javascript
const GAME_CONFIG = {
  STARTING_CASH: 500,               // 시작 자금
  STARTING_REGION: 'india',         // 시작 위치
  DAILY_LIVING_COST: 5,             // 하루 고정 운영비
  MIDDLEMAN_COMMISSION_RATE: 0.35,  // 중계무역 수수료 (0.35 = 35%)
  ROUND_DAYS: { 1: 4, 2: 8, 3: 8 }, // 라운드별 부여 일수
  // ... 상품 가격 및 이동 경로 설정
};
```
